QodeQuiz

QodeQuiz is an interactive web quiz application designed to test and practice coding knowledge in a fun and engaging way. Built with React, Next.js, and Zustand, it showcases clean architecture, reusable components, and a smooth user experience.

Highlights
    Dynamic quizzes with randomized questions
    Real-time progress tracking and results
    Responsive design for desktop and mobile
    Integration with a backend API to fetch quiz questions dynamically
    Modern frontend practices and reusable components

Tech & Skills
    Frontend: React, Next.js App Router, TypeScript
    State Management: Zustand
    Styling: TailwindCSS
    API Integration: Fetching and handling quiz data dynamically
